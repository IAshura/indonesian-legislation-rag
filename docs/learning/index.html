Cara memakai situs ini

  • Baca berurutan 01 → 10 untuk pertama kali. Setiap bab membangun di atas bab sebelumnya; tombol Lanjut → ada di bawah tiap halaman.
  • Istilah berwarna oranye bergaris putus (contoh: chunk) adalah tautan ke glosarium — diklik saja kalau belum paham.
  • Blok kode bergaya konsol selalu mencantumkan nama file asli + nomor baris, contohnya pipeline/build_dataset.py · baris 48–56. Itu bukan pseudocode — Anda bisa membukanya di proyek dan membandingkan.
  • Contoh input/output selalu data nyata yang diambil dari file proyek. Angka resmi bersumber dari pipeline/result/manifest.json; kalau ada ketidakcocokan, situs ini mencatatnya terbuka.
  • Tabel skema menjelaskan setiap field; diagram alur meringkas input → transformasi → output tiap tahap.
Tips: buka situs ini berdampingan dengan folder proyek. Mulai dari README.md (ringkasan) dan pipeline/README-build-v4.md (keputusan desain), lalu bandingkan dengan penjelasan bab yang Anda baca.

Atribusi & lisensi data

Korpus sumber proyek ini adalah dataset publik “Indonesian legislation as data: 90,588 norm units” dengan lisensi CC BY 4.0, sehingga wajib mencantumkan atribusi berikut:

ATRIBUSI WAJIBlisensi CC BY 4.0
Qausar, Prabowo, Arifin & Isa (Binus University) —Indonesian Legislation Norm-Unit Corpus, via Mendeley Data.DOI: 10.17632/8wpjvhh7g2.1 · https://data.mendeley.com/datasets/8wpjvhh7g2/1

Identitas di atas persis seperti yang tertulis di README.md dan manifest.json proyek. PDF sumber diambil dari portal JDIH pemerintah RI dan tidak didistribusikan ulang. Pipeline chunking, dataset build, evaluasi, dan lapisan validity adalah pekerjaan repositori ini.

Catatan penting (validity): korpus sumber tidak memuat status keberlakuan hukum (berlaku/diubah/dicabut). Lapisan enrich_validity.py sengaja membiarkannya null/pending_enrichment sampai ada bukti — jangan pernah mengarang status hukum. Detail di Bab 04.
