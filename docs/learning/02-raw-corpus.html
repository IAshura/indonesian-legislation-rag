Bab 02 · Sumber Data

Korpus Mentah: 90.588 Unit Norma dari 378 Peraturan

Semua yang akan dibangun nanti berangkat dari satu folder: data/corpus/. Di bab ini kita bongkar isinya — termasuk artinya tiap kolom di units.csv, cara file teks memakai penanda === PAGE n ===, dan bagaimana satu baris CSV "beralamat" persis ke potongan hukum di dunia nyata.

⏱️ ±15 menit baca Folder: data/corpus/ Bahan baku semua bab berikutnya

1. Korpus ini dari mana?

Korpus ini adalah dataset publik “Indonesian legislation as data: 90,588 norm units” (versi 1) yang diunggah ke Mendeley Data — repositori data riset — oleh Qausar, Prabowo, Arifin & Isa (Binus University), berlisensi CC BY 4.0 (boleh dipakai ulang selama mencantumkan atribusi). Nomor identitas resminya: DOI 10.17632/8wpjvhh7g2.1. Isinya adalah hasil segmentasi PDF peraturan resmi dari JDIH (portal dokumentasi hukum pemerintah RI) menjadi unit-unit kecil yang disebut unit norma: satu ayat, satu definisi, satu heading bab, satu blok penutup, dst.

Folder proyek menyimpan korpus apa adanya — aturan main di data/corpus/README-corpus.md: “jangan diubah; checksums.md5 = integritas”. Pipeline (Bab 03) hanya membaca folder ini dan menulis outputnya ke tempat lain (pipeline/result/).

3. documents.csv — register 378 peraturan (10 kolom)

Setiap PDF punya satu baris di sini. Tujuan terpentingnya: identitas resmi peraturan dibaca dari blok judul dokumen, bukan dari nama file — nama file bisa salah/kacau. README-corpus.md menyebut ini provenance contract: "setiap identitas peraturan merujuk ke blok judul, bukan nama file".

4. texts/ — teks per-halaman dengan alamat yang bisa dihitung

Untuk setiap PDF ada satu file .txt hasil ekstraksi teks. Batas halaman ditandai baris === PAGE n ===, sehingga "halaman 1", "baris ke-31" dst. punya arti yang bisa dihitung ulang oleh komputer. Berikut isi nyata awal file texts/01-UUD/UUD_1945.txt (nomor baris file ditulis di kiri):

data/corpus/texts/01-UUD/UUD_1945.txtbaris 27–35 (potongan nyata)
UNDANG-UNDANG DASARBAB IBENTUK DAN KEDAULATANPasal 1(1) Negara Indonesia ialah Negara Kesatuan, yang berbentuk Republik.(2) Kedaulatan adalah di tangan rakyat, dan dilakukan sepenuhnya oleh MajelisPermusyawaratan Rakyat.www.peraturan.go.id(baris kosong)
Cara membaca alamat provenance: baris di units.csv dihitung sebagai ordinal baris isi dalam halamannya — penanda === PAGE n === dan baris kosong tidak dihitung (aturan ini persis seperti yang dipakai fungsi pages_of() di Bab 03 dan README-corpus.md: “every non-empty line has a stable ordinal within its page”). Jadi page 1, baris 31–32 = baris file ke-32 dan ke-33 = persis teks “(2) Kedaulatan adalah di tangan rakyat, … oleh Majelis / Permusyawaratan Rakyat.” — cocok sempurna dengan isi text_original di atas.

Inilah janji provenance korpus: setiap unit harus bisa ditemukan kembali di (dokumen, halaman, rentang baris) — dan Bab 09 akan memverifikasinya ulang, baris demi baris.

5. checksums.md5 — pembuktian "tidak ada yang berubah"

MD5 menghasilkan sidik jari pendek (32 karakter heksadesimal) dari isi sebuah file. Ubah satu koma pun, sidik jarinya berubah total. File checksum berisi pasangan sidik jari + nama file — baris nyatanya:

Fungsi praktisnya bagi pipeline: build build_dataset.py juga menghitung SHA-256 (sepupu MD5 yang lebih kuat) untuk tiap CSV dan mencatatnya di manifest — jejak audit bahwa hasil build benar-benar dari korpus ini.
