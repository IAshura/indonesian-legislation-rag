Bab 05 · Embedding

Mengubah 63.231 Potongan Hukum Menjadi Angka yang “Paham Makna”

Bab sebelumnya menghasilkan teks siap-embed. Bab ini menjalankan model embedding: teks masuk, keluar sebagai vektor angka. Proyek ini mencoba dua model berbeda dan menyimpan keduanya berdampingan — kita pelajari caranya, sekaligus dua teknik pooling yang berbeda (mean-pooling e5 vs last-token Qwen3).

⏱️ ±15 menit baca File: embed_example.py · emb_paths.py · verify_embeddings.py · notebook Colab Artefak: 63.231 × (1024 & 2560) float32

1. Konsep: apa yang sebenarnya terjadi?

Model embedding adalah jaringan saraf (dilatih dulu pada teks raksasa) yang memetakan teks ke titik di “ruang makna” berdimensi banyak. Analogi paling sederhana: peta 2-dimensi. Kota yang budayanya mirip berdekatan di peta; di ruang embedding, kalimat yang maknanya mirip berdekatan di ruang 1.024-dimensi. “Jarak” diukur dengan cosine similarity (Bab 01) — dan karena semua vektor dipaksa L2-normal (panjang 1), jarak itu cukup dihitung dengan perkalian dot.

embedding_input (teks)“UUD - Bab I Pasal 1 Ayat (2): (2) Kedaulatan…”
→
tokenizerteks dipecah token → angka ID
→
model (jaringan saraf)1.024/2.560 lapisan keadaan tersembunyi
→
pooling + L2-normalrata-rata/last-token → vektor panjang 1
→
vektor float32[-0.0545, -0.0987, -0.0038, …] × 1.024

Vektor nyata di atas (8 angka pertama dari 1.024) adalah vektor chunk uud-1945::p::1::02 dari artefak Qwen3-0.6B — norm-nya tepat 1,0000. Angka negatif/positif/pecahan kecil adalah wajar; yang penting arahnya.

2. Dua teknik pooling di proyek ini

Pooling = cara meringkas deretan keadaan tersembunyi tiap token menjadi satu vektor. Dua model di proyek ini memakai cara berbeda — dan itu berkonsekuensi teknis serius:

mean-pooling — e5 (embed_example.py)last-token — Qwen3 (notebook Colab)
CaraRata-rata tertimbang semua token: (hid * mask).sum(1) / mask.sum(1) — token “padding” diabaikan lewat attention maskAmbil keadaan token terakhir saja (padding kiri): hs[:, -1] — model decoder dilatih khusus agar token terakhir “menampung” seluruh makna
Prefiks/instruksiAwalan teks: passage: … untuk dokumen, query: … untuk pertanyaan (otomatis di kode, baris 56–57)Instruksi tugas di sisi query: Instruct: {instruksi}\nQuery: {q} (diambil dari meta.json)
Dimensie5-base 768 / e5-large 1024Qwen3-0.6B: 1024 · Qwen3-4B: 2560 (MRL bisa dipangkas: keep_dim)
Metadanyameta.json: pooling tidak ditulis (default mean)meta.json: "pooling": "last_token" + query_instruction
Aturan besi (dari README-build-v4): model index = model query — ganti model = embed ulang semua dokumen. Vektor mean-pooling e5 tidak boleh dibandingkan dengan vektor last-token Qwen3; itu seperti mencocokkan dua kamus sandi berbeda. Penanda versinya tersimpan di meta.json.

3. Bedah embed_example.py

Filter: siapa yang di-embed? (baris 30–40)

pipeline/embed_example.pybaris 30–40
def load(path, part, include_fragments): out = [] with open(path, encoding="utf-8") as f: for line in f: r = json.loads(line) if part != "all" and r["part"] != part: continue if r.get("is_fragment") and not include_fragments: continue out.append(r) return out

Default: hanya part=norma dan fragmen dilewati (bendera di Bab 03 akhirnya dipakai di sini). Hitungannya pas: 74.218 chunk − 10.987 (admin + fragmen) = 63.231 record — persis isi meta.json kedua model. Indeks bersih tanpa membuang satu baris pun dari dataset.

Encode + mean-pooling (baris 43–67)

pipeline/embed_example.pybaris 53–64 (inti)
with torch.no_grad(): for i in range(0, len(texts), batch): ch = texts[i:i + batch] if is_e5 and prefix: ch = [f"{prefix}: {t}" for t in ch] enc = tok(ch, padding=True, truncation=True, max_length=max_len, return_tensors="pt").to(dev) hid = model(**enc).last_hidden_state m = enc["attention_mask"].unsqueeze(-1) vec = (hid * m).sum(1) / m.sum(1).clamp(min=1e-9) vec = torch.nn.functional.normalize(vec, p=2, dim=1) out.append(vec.float().cpu().numpy())

6. Verifikasi: verify_embeddings.py

Sebelum dipakai, artefak diuji empat lapis (dokstring baris 9–13):

  1. Header .npy dibaca manual byte demi byte (baris 30–40) — dtype harus <f4 (float32), shape (n, dim).
  2. ids.jsonl — jumlah baris = n; kolom wajib terisi; chunk_id unik (baris 61–72).
  3. meta.json — count & dim konsisten dengan npy (baris 74–83).
  4. Sampel 1.000 vektor — norm L2 harus 0,98–1,02; tidak boleh ada NaN/Inf (baris 85–101).
pipeline/verify_embeddings.pybaris 90–101 (inti)
idx = np.linspace(0, n - 1, num=min(1000, n), dtype=int) vecs = np.load(npy, mmap_mode="r")[idx] norms = np.linalg.norm(vecs.astype("float32"), axis=1) bad_norm = int(((norms < 0.98) | (norms > 1.02)).sum()) if not np.isfinite(vecs).all(): problems.append("ada NaN/Inf di sampel vektor") print(f"[vektor] sampel {len(idx)} norm L2: " f"min={norms.min():.4f} max={norms.max():.4f} [OK]")

mmap_mode="r" berarti numpy tidak memuat seluruh 259–647 MB ke RAM — hanya baris yang disampel. Hasil nyata di README kedua folder model: “Norm L2 1.0000 (sampel 1000 — tervalidasi verify_embeddings.py)”.

7. Embedding Qwen3 di Colab — ringkas notebook

Notebook pipeline/colab/embed_qwen3_06b_colab.ipynb (10 cell) menjalankan embedding + eval di GPU T4 gratis Colab, dengan fitur produksi: checkpoint atomik & resume lintas sesi (cell 5), lalu hasil diunduh ke folder model di Windows (cell 8). Cell kuncinya:

embed_qwen3_06b_colab.ipynbcell 3 & 4 (inti)
# cell 3 — konfigurasiMODEL_ID = 'Qwen/Qwen3-Embedding-0.6B' # ← ganti dari 4B ke 0.6BBATCH_SIZE = 32 # 0.6B ringan — 32 aman di T4KEEP_DIM = None # None = 1024 penuh; MRL bisa lebih kecil (32–1024)QUERY_INSTR = ('Given a user question about Indonesian legislation, ' 'retrieve the most relevant legal provisions (norma) ' 'that answer the question')# cell 4 — muat model + pooling last-token (padding KIRI)tok = AutoTokenizer.from_pretrained(MODEL_ID, padding_side='left')mdl = AutoModel.from_pretrained(MODEL_ID, torch_dtype=torch.float16, attn_implementation='sdpa').to('cuda').eval()

Catatan: MRL (Matryoshka Representation Learning) memungkinkan memangkas dimensi vektor (mis. 1024 → 512) tanpa melatih ulang — trade-off ukuran vs kualitas; proyek ini memakai dimensi penuh (keep_dim = None). float16 = versi angka setengah-presisi agar muat di memori GPU.
