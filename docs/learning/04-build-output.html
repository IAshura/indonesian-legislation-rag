4. parents.jsonl & parents_windows.jsonl

Parent = “wadah pasal utuh”. Record uud-1945::p::1 sudah diperlihatkan di Bab 03 §9: perhatikan child_ids (daftar chunk), text (pasal utuh), dan window_ids. Parent ada dua jenis:

parent_kindPola IDContoh nyata
pasal{document_id}::p::{pasal}uud-1945::p::1 · perlembaga-nomor-4-tahun-2023::p::87
administratif_block{document_id}::adm::{nn}uud-1945-perubahan-kedua-2000::adm::001

Window lahir hanya dari parent panjang: 1.632 parent dipecah jadi 14.689 window (sisa parent pendek = 1 window utuh). Record window uud-1945::p::1::w01 sudah diperlihatkan di Bab 03 §9 — field-nya: window_id, parent_id, document_id, part, citation_str, char_len, text. Pola ID: {parent_id}::w{nn} — w01, w02, dst.

6. quarantine.jsonl — terbuang, tapi beralasan

2.209 baris, masing-masing dengan alasan. Dua contoh asli:

pipeline/result/quarantine.jsonldua record asli
{ "reason": "duplicate_norm", "unit_id": 400611, "file_name": "UUD 1945 Perubahan Kedua_2000.pdf", "unit_type": "body", "quality_flag": "structural_admin", "pasal": "Pasal 36C", "ayat": null, "page_number": 6, "line_start": 16, "line_end": 17, "text_preview": "WAKIL KETUA, Ttd." }{ "reason": "heading_like_body", "unit_id": 400859, "file_name": "TAP_MPR_NO_II_1983.pdf", "unit_type": "body", "quality_flag": "structural_heading", "pasal": "Pasal 1", "ayat": null, "page_number": 2, "line_start": 10, "line_end": 10, "text_preview": "b) Bab II Pola Dasar Pembangunan Nasional;" }

Kalimat tanda tangan “WAKIL KETUA, Ttd.” muncul berulang di banyak halaman UUD Perubahan Kedua — duplikat exact memang benar di-quarantine. Dan “b) Bab II Pola Dasar…” adalah serpihan daftar isi, bukan norma — benar juga. Field setiap record: reason, unit_id, file_name, unit_type, quality_flag, pasal, ayat, page_number, line_start, line_end, text_preview (maks 140 char) — semuanya untuk memudahkan audit manual.

7. validity.jsonl — jangan pernah mengarang status hukum

Korpus sumber tidak memuat status keberlakuan. Prinsip file ini (dokstring enrich_validity.py baris 6): “JANGAN PERNAH menebak. Tidak yakin → tetap null, catat alasan”. Mode offline menulis 378 baris seperti ini:

Lihat isinya: txt (teks chunk) adalah versi bersih dari src (baris sumber dengan kop halaman “2011, no.376” menempel). Isi norma utuh — hanya kepala baris sumber yang ber-noise. Transparansi beginilah yang membuat 98% bisa dipercaya.

9. Ringkasan bab

  • Tujuh file saling mengunci via ID: chunk → parent (parent_id) → window (window_ids) → dokumen (document_id).
  • Funnel beralasan: 90.588 = 74.218 chunk + 2.209 quarantine + 14.161 heading — nol hilang.
  • QA gate: 300 sampel → 98% match → PASS; kegagalan dicatat terbuka, bukan disembunyikan.
  • Validity: status hukum kosong sampai ada bukti — prinsip “jangan mengarang”.
Istilah baru bab ini: manifest, funnel, chunk yatim, validity, quarantine (ulang).
